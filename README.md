# 家乡文化二维码 🌶️

天等县城西小学 **四年级** 家乡文化课堂工具。学生点词拼句 → 生成二维码 → 挂到作品墙互相点赞评价。

> 线上地址：https://hometown-culture-qr.app.workbuddy.host/
>
> ⚠️ 面向小学生，**全站不使用生成式人工智能**（原「AI 帮写」已移除，改为「点词拼句 + 句子自动填入」）。

## 四个页面

| 页面 | 文件 | 说明 |
|---|---|---|
| ① 学生生成器 | `index.html` | 选主题 → 每行点一个词 → 句子自动填入 → 生成二维码 → 提交作品墙 |
| ② 作品墙 | `wall.html` | 看大家的作品、扫码看大图、点赞 + 星级评价 + 点选鼓励语 |
| ③ 问卷 | `survey.html` | 课前 / 课中 / 课后三份问卷 |
| ④ 教师数据面板 | `admin.html` | 作品与问卷数据、导出 CSV、一键清除 |

管理员密码：`cx2026`（作品墙右上角「🔒 管理员」、数据面板登录都用它）

## 学生身份（课堂版）

- **不填姓名**：学生选择**学号 1—60 号**。
- **班级**：默认**四年级**，可选四 / 五 / 六年级 + **1—8 班**（班级数量改 `_src/*.tpl.html` 里的 `CLASSES` 变量）。
- 作品墙上显示为「`15号` · `四（2）班`」——匿名且可辨识。

## 目录结构

```
_文化二维码/
├── index.html / wall.html / survey.html / admin.html   ← 构建产物（可直接部署）
├── _src/
│   ├── _build.py                 构建脚本：模板 → 成品 HTML
│   ├── index.tpl.html            生成器模板
│   ├── wall.tpl.html             作品墙模板
│   ├── survey.tpl.html           问卷模板
│   ├── admin.tpl.html            数据面板模板
│   ├── qrcode.js                 二维码库（构建时内联，MIT）
│   ├── sdk.global.js             云服务 SDK（构建时内联）
│   └── cloud-config.json         云服务配置 + DeepSeek key
└── .gitignore
```

## ★ 修改流程（重要）

**只改 `_src/*.tpl.html`**，改完必须重新构建，外层 `index.html` 等才会更新：

```bash
python _src/_build.py
```

构建后发布：

```bash
# 发布到 workbuddy.host（覆盖同一链接）
```

## 技术说明

- 四个页面全部**单文件**，零外链（二维码库、云 SDK 均内联），双击即用。
- 作品墙 / 问卷数据存 **WorkBuddy 云服务**（`cloud.database`），因此页面**必须从部署域名访问**，不能塞进别的站点内嵌。
  → 这也是「哒哒工作台」里用**外链卡片**而不是内嵌的原因。
- 留言区有一道本地敏感词闸 `scanBad()`（非 AI，是给小学生的安全底线，勿删）。
